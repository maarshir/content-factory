Конвейеры n8n для импорта, без ключей.

- `collect.json`: сбор. Расписание, «Настройки», ленты RSS, отбор с учётом журнала, запрос к нейросети, разбор ответа, черновик редактору в бот с кнопками.

Код узлов Code вклеен из `src/nodes/` командой `npm run build`, правка только в `src/`. Импорт и настройка в [docs/setup.md](../docs/setup.md).
