Промпты для нейросети, по одному на площадку.

- `telegram.md`: пост для Телеграм-канала с дайджестом новостей ИИ. Поля `{{title}}`, `{{description}}`, `{{link}}`, `{{maxLength}}` подставляет `fillPrompt` из `src/post.js`. Модель отвечает объектом JSON с оценкой релевантности и текстом, его разбирает `src/parse.js`.
- `vk.md`: пост для сообщества ВКонтакте. Те же поля и тот же ответ JSON, текст без разметки: ВКонтакте её не показывает.
- `max.md`: пост для канала в MAX. Те же поля и тот же ответ JSON, текст без разметки: заголовок жирным и ссылку добавляет `buildMaxPost`.
- `rewrite.md`: переписывание черновика по пометке редактора. Поля `{{title}}`, `{{link}}`, `{{draft}}` (прежний текст без заголовка и разметки), `{{note}}`, `{{maxLength}}`; ответ в том же формате JSON.
