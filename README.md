# content-factory

Собирает новости из RSS, отбирает подходящие, переписывает их нейросетью под Телеграм и публикует после проверки редактором. Конвейер на n8n.

Статус: в работе. Готов код узлов в `src/` (отбор, повторы, сборка поста, разбор ответа нейросети, журнал, список лент), конвейеров n8n пока нет.
