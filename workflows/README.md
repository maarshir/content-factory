Конвейеры n8n для импорта, без ключей.

- `collect.json`: сбор. Расписание, «Настройки», ленты RSS, отбор с учётом журнала, запрос к нейросети, разбор ответа, черновик редактору в бот с кнопками.
- `editor.json`: бот редактора. Нажатия кнопок и ответы на черновик из чата редактора: очередь на публикацию, отказ с причиной, переписывание нейросетью с пометкой и новый черновик.
- `publish.json`: публикация. Раз в 15 минут первый пост из очереди уходит в канал с учётом интервала и тихих часов, итог (номер сообщения или ошибка Телеграма) пишется в журнал.

Код узлов Code вклеен из `src/nodes/` командой `npm run build`, правка только в `src/`. Импорт и настройка в [docs/setup.md](../docs/setup.md).
