# content-factory

Собирает новости из RSS, отбирает подходящие, переписывает их нейросетью под Телеграм и публикует после проверки редактором. Конвейер на n8n.

Статус: в работе. Готовы код узлов в `src/` (отбор, повторы, сборка поста, разбор ответа нейросети, журнал, список лент), конвейеры сбора, бота редактора и публикации по расписанию в `workflows/`; описание и проверка в n8n в работе.
