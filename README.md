# content-factory

Собирает новости из RSS, отбирает подходящие, переписывает их нейросетью под Телеграм и публикует после проверки редактором. Конвейер на n8n.

Статус: в работе. Готовы код узлов в `src/` (отбор, повторы, сборка поста, разбор ответа нейросети, журнал, список лент) и конвейер сбора `workflows/collect.json`; бот редактора и публикация по расписанию в работе.
