Код узлов Code для n8n: отбор, отсев повторов, сборка поста, разбор ответа нейросети, журнал; список лент RSS.

- `filter.js`: отбор по ключевым словам и стоп-словам, отсев повторов по ссылке (без меток utm, www и якоря) и по похожести заголовков с порогом. Настройки в `filter.config.json`. Файл без зависимостей: в узел Code его можно вставить целиком и вызвать `filterItems(items, config, seen)`, где `seen` это уже собранные записи из журнала. Каждый отказ возвращается с причиной.
- `post.js`: сборка поста для Телеграма с разметкой HTML. Экранирует `&`, `<`, `>`, обрезает текст до лимита (4096 знаков сообщения или 1024 подписи к картинке) по предложению или слову, в конце всегда ссылка на источник; без ссылки пост не собирается. `fillPrompt` подставляет поля новости в шаблон из `prompts/`. Для ВКонтакте `buildVkPost`: простой текст без разметки, ссылка на источник последней строкой, предел 4096 знаков (в описании wall.post предел не указан, взят свой с запасом). Для MAX `buildMaxPost`: та же разметка HTML, что у Телеграма, предел 4000 знаков вместе с тегами, `format: html`. `platformOf` читает площадку из поля `PLATFORM` узла «Настройки» (`telegram` по умолчанию, `vk` или `max`), `buildPostFor` собирает пост для неё.
- `parse.js`: разбор ответа нейросети `{"relevance": 0..10, "text": "..."}`. Достаёт JSON из блока кода и пояснений, проверяет шкалу оценки, порог релевантности, длину текста и признаки отказа модели; каждый отказ с причиной.
- `log.js`: журнал в SQLite. `createLog(db)` принимает базу node:sqlite (`DatabaseSync`, Node 22.5+) или better-sqlite3. Статусы `collected`, `queued` (в очереди на публикацию, только с черновиком), `rejected`, `published`; журнал прежней схемы переносится при `init()`; у отказа обязательна причина, у публикации номер сообщения в канале; опубликованное не откатывается, повтор ссылки (с учётом меток utm) новой строки не создаёт. `drafted` хранит черновик поста, `byId` находит запись по номеру из кнопки бота. `seen(дней)` отдаёт записи для `filterItems`, `stats()` считает статусы и частые причины отказа. Тесты с базой идут на Node 22 (tests.yml), на Node 20 пропускаются.
- `editor.js`: бот редактора. `parseUpdate` разбирает обновление Телеграма (нажатие `pub:`, `rew:`, `rej:` или ответ на черновик) и пропускает только чат редактора, `applyAction` ставит в очередь, отклоняет с причиной или готовит переписывание; `draftBody` достаёт текст черновика для промпта.
- `plain.js`: выбор текста под площадку при публикации. Площадка поста задаётся при сборе (`PLATFORM` в «Настройках» `collect.json`), в журнал она не пишется: `isTelegramPost` узнаёт черновик Телеграма или MAX по тегам HTML. `textFor` переводит в простой текст только такие черновики и только для ВКонтакте (`htmlToPlain`: теги убираются, сущности раскрываются, ссылка источника уходит на отдельную строку); пост ВКонтакте для Телеграма экранируется под HTML.
- `retry.js`: повтор отправки в Телеграм при 429. `telegramError` достаёт `retry_after` из ответа Bot API или из текста ошибки узла n8n, `planRetry` решает: ждать и повторить (до 3 раз, не дольше 60 секунд) или записать причину в журнал. `markUndelivered` пишет причину у записи, черновик которой не дошёл до редактора, статус остаётся `collected`.
- `overlap.js`: проверка пересказа на дословные совпадения. `overlap` режет пост и описание из ленты на слова (нижний регистр, ё как е) и считает, какая доля цепочек из 5 слов подряд в посте встречается в описании, и находит самый длинный общий кусок. `overlapNote` возвращает строку для редактора, если доля выше порога (20% по умолчанию).
- `queue.js`: очередь публикации поверх журнала. `next(config)` выбирает пост, поставленный в очередь раньше других, с учётом интервала после прошлой публикации, тихих часов и числа неудачных попыток; `failed` пишет ошибку Телеграма, ВКонтакте или MAX и оставляет пост в очереди, `published` ставит номер сообщения в канале.
- `publish.config.json`: правила публикации: интервал между постами, тихие часы и часовой пояс, число попыток отправки.
- `sources.json`: ленты RSS для дайджеста новостей ИИ на русском, проверены 01.10.2026. `topic` про ИИ целиком, `general` общие новости техники, из них нужное отбирает `filter.js`.
- `nodes/`: код узлов Code конвейеров. Строки `// @include` при сборке (`npm run build`) заменяются файлами выше, готовый код вклеивается в `workflows/*.json`.
